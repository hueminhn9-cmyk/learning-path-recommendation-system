# 🚀 Quick Start Guide - AI Student Learning Path System

## ✅ Your App is Running!

**Access it at:** `http://localhost:8502`

---

## 🎯 5-Minute Setup

### **Step 1: Login (30 seconds)**
1. Open browser → http://localhost:8502
2. Enter email: `student@college.edu`
3. Enter password: (any password)
4. Click **Login**

### **Step 2: Take First Assessment (2 minutes)**
1. Click **📝 Assessment** in sidebar
2. Fill in your details:
   - Full Name
   - Roll Number
   - Subject (e.g., Data Science)
   - Marks (0-100)
   - Interest Level (Low/Medium/High)
   - Study Time (0.5-8 hours)
3. Click **Generate Learning Path**

### **Step 3: View Recommendations (1 minute)**
1. See your predicted level (Beginner/Intermediate/Advanced)
2. Read personalized tips
3. View recommended resources
4. Check confidence score

### **Step 4: Track Progress (1 minute)**
1. Click **📈 Progress**
2. See assessment history
3. View performance trends
